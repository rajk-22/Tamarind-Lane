# Tamarind Lane

A complete restaurant website with online table booking, built with Flask, SQLite and vanilla JavaScript. Tamarind Lane is a fictional modern South Indian restaurant in Bengaluru, designed as a template for real small-business clients.

## Highlights
- Live availability: guests pick a date and see which times are free
- Booking rules for closed days, seat capacity, advance window and lead time
- Email notifications to the owner and the guest
- Admin panel to confirm, cancel and export bookings as CSV
- Fully responsive, with accessible forms and keyboard focus styles
- All content (menu, hours, capacity) lives in one file, so it's easy to reuse for new clients

## Tech stack
Python, Flask, Flask-SQLAlchemy, SQLite, Jinja2, HTML, CSS, JavaScript
